## Policy: ambiguity resolution (2026-09-29, user request)
Escalation ladder before anything reaches the user as needs_review:
crop re-read → Opus context inference (melody, meter, neighbouring chords) → web corroboration
(published chord charts via Gemini + Google Search grounding, aligned by scale degree) → needs_review.
Web evidence is corroboration only: it never overrides a clearly-read chord; it can break ties or
confirm an insertion together with inference. Structural re-segmentation needs valid beat sums AND
pixel evidence of a barline. Every automatic change is recorded as auto_fixed with its evidence list.
